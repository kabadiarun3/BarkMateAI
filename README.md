# BarkMate AI

Android-first dog behaviour and communication assistant MVP.

## MVP contents
- Expo + React Native + TypeScript mobile app
- FastAPI backend with health, audio-upload demo, and owner-context feedback endpoints
- Backend automated tests and GitHub Actions workflow
- Render Free demo deployment blueprint
- Android EAS APK preview build profile
- AI dataset annotation template and model development plan

## Scientific limitations
Audio analysis is currently a demo stub. It does not translate barks or reliably classify emotion. A real model requires a consented dataset, expert annotations, dog-level train/test splits, and independent validation.

## Deployment caution
The Render Free service uses ephemeral storage and is for disposable testing only. Do not use it for customer data.

See docs/STATUS.md for delivery status and setup instructions.
